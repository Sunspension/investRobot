# investRobot

investRobot - это робот для алгоритмической торговли на бирже [Тинькофф Инвестиций](https://www.tinkoff.ru/invest/)
посредством [Tinkoff Invest API](https://github.com/Tinkoff/investAPI).

[Документация для разработчиков](https://karpp.github.io/investRobot/)

## 📋 Правила разработки

**Важно!** Перед началом работы ознакомьтесь с [правилами проекта](docs/project_rules.md):
- ❌ **НИКОГДА не делать импорты внутри функций**
- ❌ **НИКОГДА не использовать `print()`**
- ✅ **ВСЕГДА использовать `get_logger(__name__)`**
- ✅ **Использовать Dependency Injection**

## Функциональные возможности

* **Автоматическая торговля** любыми ценными бумагами
* **Реализация собственного торгового алгоритма** с поддержкой множественных стратегий
* **Выставление и отмена** как рыночных, так и лимитных торговых поручений
* **Ведение статистики** и выдача краткого результата
* **Логирование всех операций** с возможностью установки уровня логирования
* **Подключение визуализации** для анализа результатов
* **🆕 Реальная торговля** с полным управлением рисками
* **🆕 Бэктестинг** с оптимизацией параметров
* **🆕 Проверка торговых часов** и автоматическое управление сессиями


## Запуск робота

### 🚀 Быстрый старт

1. Установите зависимости: `python3.10 -m pip install -r requirements.txt`
2. Настройте конфигурацию в `config_data/config.py`
3. Выберите режим работы:

#### 📊 Бэктестинг и оптимизация:
```bash
# Загрузка данных
python scripts/main_stats.py load --figi FUTIMOEXF000 --from "2024-12-01" --to "2024-12-31"

# Оптимизация параметров
python scripts/main_stats.py optimize --figi FUTIMOEXF000 --from "2024-12-02 07:00" --to "2024-12-30 18:59"
```

#### 🤖 Реальная торговля:
```bash
# Тестирование в песочнице
python scripts/main_trading.py --figi FUTIMOEXF000 --deposit 50000

# Реальная торговля (осторожно!)
python scripts/main_trading.py --live-trading --figi FUTIMOEXF000
```

#### 📈 Визуализация:
```bash
# Запуск визуализатора
./tools/run_visualizer.sh

# Или напрямую
python tools/market_visualizer.py
```

#### 🚀 Оптимизация:
```bash
# Оптимизация для всех дней
./tools/run_optimization.sh

# Мониторинг оптимизации
./tools/monitor_all_days.sh
```

### 📁 Структура проекта

## Торговая стратегия

В качестве демонстрации представлена одна торговая стратегия, основанная на индиакторе двух скользящих средних.
Строятся линии двух скользящих средних, короткого и длинного. Интервалы задаются в параметрах стратегии.
При пересечении линий считается, что тренд цены меняется, и нужно либо покупать (в случае, если короткое среднее выше
длинного), либо продавать (в обратном случае).
