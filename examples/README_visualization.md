# Визуализация торговли в реальном времени

## 🚀 Обзор

Система визуализации для торговли в реальном времени с использованием оптимальных параметров стратегии, полученных в результате оптимизации.

## 📊 Возможности

### ✅ Реализовано:
- **Веб-интерфейс** с обновлением в реальном времени
- **Оптимальные параметры** стратегии (MACD(6,12,7) ATR(10) L(6-18) P(0.15))
- **Индикаторы MACD** с сигнальной линией и гистограммой
- **Торговые сигналы** (покупка/продажа) с визуальными маркерами
- **Статистика сигналов** в реальном времени
- **Демо-режим** с симулированными данными

### 🔄 В разработке:
- Подключение к реальному Tinkoff API
- Автоматическое размещение ордеров
- Управление рисками
- Логирование торговых операций

## 🎯 Оптимальные параметры стратегии

На основе анализа 8 дней с 100% прибыльностью:

```
MACD(6,12,7) ATR(10) L(6-18) P(0.15)
```

### Критические параметры (100% стабильность):
- **macd_fast: 6** - 100% в топ-100
- **peak_prominence: 0.15** - 100% в топ-100

### Высокоэффективные параметры:
- **macd_slow: 12-14** - оптимальный диапазон
- **macd_signal: 7-8** - доминирующие значения
- **atr_period: 6-10** - адаптивный диапазон
- **lookback_min: 6-7** - оптимальный диапазон
- **lookback_max: 18-24** - широкий диапазон

## 🚀 Запуск

### Демо-версия (рекомендуется для тестирования):
```bash
./run_demo_visualizer.sh
```

### Реальная торговля (требует настройки API):
```bash
./run_realtime_visualizer.sh
```

## 🌐 Веб-интерфейс

После запуска откройте в браузере: **http://127.0.0.1:8050**

### Интерфейс включает:
- **Текущая цена** в реальном времени
- **Время последнего обновления**
- **Статус рынка** (открыт/закрыт/демо)
- **Параметры стратегии**
- **Статистика сигналов** (покупка/продажа)
- **Интерактивный график** с:
  - Свечами OHLCV
  - MACD индикаторами
  - Торговыми сигналами

## ⚙️ Настройка для реальной торговли

### 1. Создайте файл `.env`:
```env
TINKOFF_TOKEN=your_tinkoff_token
TINKOFF_ACCOUNT=your_account_id
SANDBOX_TOKEN=your_sandbox_token
```

### 2. Установите зависимости:
```bash
pip install tinkoff-invest-grpc-client
```

### 3. Запустите реальную версию:
```bash
./run_realtime_visualizer.sh
```

## 🔧 Технические детали

### Архитектура:
- **Frontend:** Dash + Plotly (веб-интерфейс)
- **Backend:** Python + asyncio (обработка данных)
- **API:** Tinkoff Invest API (реальные данные)
- **Стратегия:** SignalManager с оптимизированными параметрами

### Производительность:
- **Обновление:** каждые 1-2 секунды
- **Память:** ограничена 100-200 свечами
- **Сигналы:** ограничены 50-100 последними

## ⚠️ Важные замечания

1. **Демо-версия** использует симулированные данные
2. **Реальная торговля** требует настройки API токенов
3. **Песочница** рекомендуется для тестирования
4. **Риски:** торговля на реальные деньги несет риски потерь
