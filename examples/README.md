# Examples

Коллекция примеров и демонстраций для торгового робота.

## Основные файлы

### `main.py`
Главный файл для запуска торгового робота. Содержит пример настройки и запуска торговой сессии.

### `example_trading.py`
Базовый пример торговли с использованием моков. Показывает, как настроить и запустить торговую сессию.

## Документация

### `docs/tinkoff_api_interface_usage.md`
Подробное описание использования интерфейса TinkoffAPIClientable с примерами кода и объяснением преимуществ.

## Утилиты

### `account.py`
Утилита для работы с аккаунтом - получение информации, настройка параметров.

### `benchmark_gpu.py`
Бенчмарк производительности GPU для оптимизации стратегий.

## Скрипты оптимизации

### `parallel_optimize.sh`
Скрипт для параллельной оптимизации параметров стратегий.

### `parallel_optimize_test.sh`
Тестовый скрипт для проверки параллельной оптимизации.

## Документация

### `README_visualization.md`
Документация по системе визуализации торговых данных.
