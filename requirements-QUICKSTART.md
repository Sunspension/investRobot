# Быстрый старт с зависимостями

## 🚀 Выберите нужную конфигурацию:

### 1. **Полная конфигурация** (с веб-интерфейсом)
```bash
pip install -r requirements.txt
```
**Для:** Полноценная торговля с визуализацией, веб-интерфейсом, графиками

### 2. **Базовая конфигурация** (только торговля)
```bash
pip install -r requirements-core.txt
```
**Для:** Торговая логика без UI, серверные приложения, headless режим

### 3. **С опциональными пакетами**
```bash
pip install -r requirements.txt -r requirements-optional.txt
```
**Для:** Разработка, оптимизация, GPU ускорение

- **Продакшн сервер** → `requirements-core.txt`
