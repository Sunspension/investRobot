# Changelog - InvestRobot

## [1.0.1] - 2025-09-14

### 🔧 Исправления

#### Критические исправления
- **Исправлена ошибка NoneType в MarketDataStream.stop()**
  - Убрана проверка `asyncio.iscoroutine(result)`
  - Упрощен код до простого синхронного вызова `self._stream_manager.stop()`
  - Исправлена ошибка `object NoneType can't be used in 'await' expression`

- **Улучшена обработка исключений в SessionController**
  - Добавлен вызов `await self.stop()` при `KeyboardInterrupt`
  - Добавлен вызов `await self.stop()` при критических ошибках
  - Обеспечен graceful shutdown во всех сценариях
