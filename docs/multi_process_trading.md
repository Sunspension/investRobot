# Многопроцессная система торговых роботов

## Обзор

Эта система позволяет запускать независимых торговых роботов для нескольких счетов в отдельных процессах. Каждый робот работает полностью независимо со своими:

- Торговой сессией и стратегиями
- Управлением рисками
- Отслеживанием портфеля
- Панелью визуализации (опционально)
- Логированием

## Преимущества архитектуры

### 🔄 **Изоляция процессов**
- Каждый счёт работает в отдельном процессе ОС
- Полная изоляция предотвращает влияние сбоев на другие счета
- Независимые области памяти и ресурсы

### 📊 **Независимый мониторинг**
- У каждого робота своя панель визуализации на уникальном порту
- Отдельные файлы логов для каждого счёта
- Индивидуальное отслеживание производительности

### ⚡ **Масштабируемость**
- Добавление/удаление счетов без влияния на работающих роботов
- Простое горизонтальное масштабирование на несколько машин
- Распределение использования ресурсов по ядрам CPU

### 🛡️ **Управление рисками**
- Изоляция рисков на уровне счёта
- Индивидуальные лимиты позиций и потерь
- Независимые параметры стратегий для каждого счёта

## Быстрый старт

### 1. Создание файла конфигурации

```bash
python run_multi_account.py --create-config
```

Это создаёт `accounts_config.json` с примером конфигурации.

### 2. Редактирование конфигурации

Отредактируйте `accounts_config.json` с данными ваших счетов:

```json
{
  "accounts": [
    {
      "account_id": "your_account_1",
      "token": "your_token_here", 
      "sandbox_token": "your_sandbox_token",
      "figi": "FUTIMOEXF000",
      "deposit": 100000.0,
      "max_daily_loss": 5000.0,
      "enable_visualization": true,
      "visualization_port": 8050,
      "process_name": "robot_futures"
    },
    {
      "account_id": "your_account_2",
      "token": "your_token_here",
      "sandbox_token": "your_sandbox_token", 
      "figi": "SBER",
      "deposit": 50000.0,
      "max_daily_loss": 2500.0,
      "enable_visualization": true,
      "visualization_port": 8051,
      "process_name": "robot_stocks"
    }
  ]
}
```

### 3. Запуск многоаккаунтной системы

**Интерактивный режим (рекомендуется):**
```bash
python run_multi_account.py --config accounts_config.json --interactive
```

**Режим Daemon:**
```bash
python run_multi_account.py --config accounts_config.json --daemon
```

**Тест одного счёта:**
```bash
python run_multi_account.py --account-id "test_account" --token "your_token" --figi "FUTIMOEXF000"
```

## Интерактивные команды

В интерактивном режиме вы можете управлять роботами с помощью этих команд:

- `status` - Показать статус всех роботов
- `start` - Запустить всех роботов
- `stop` - Остановить всех роботов
- `start <account_id>` - Запустить конкретного робота
- `stop <account_id>` - Остановить конкретного робота
- `restart <account_id>` - Перезапустить конкретного робота
- `help` - Показать справку
- `quit` / `exit` - Выйти из программы

## Параметры конфигурации

### Конфигурация счёта

```python
@dataclass
class AccountConfig:
    # Обязательные
    account_id: str              # ID счёта Tinkoff
    token: str                   # API-токен Tinkoff
    sandbox_token: str           # Токен sandbox
    
    # Торговля
    figi: str = "FUTIMOEXF000"   # Инструмент для торговли
    deposit: float = 100000.0    # Начальный депозит
    
    # Управление рисками
    max_daily_loss: float = 5000.0        # Максимальные дневные потери
    max_position_size: float = 50000.0    # Максимальный размер позиции
    stop_loss_threshold: float = 2.0      # Порог стоп-лосс %
    
    # Сессия
    auto_close_positions: bool = True     # Автозакрытие в конце дня
    end_of_day_close: bool = True        # Включить закрытие в конце дня
    close_time: time = time(23, 50)      # Время закрытия
    
    # Визуализация
    enable_visualization: bool = True     # Включить веб-панель
    visualization_port: int = 8050       # Порт панели
    visualization_host: str = "127.0.0.1" # Хост панели
    
    # Процесс
    process_name: Optional[str] = None   # Имя процесса
    log_level: str = "INFO"              # Уровень логирования
```

## Управление портами

Система автоматически управляет портами визуализации:

- Каждый счёт получает уникальный порт (8050, 8051, 8052, и т.д.)
- Автоматическое обнаружение конфликтов портов
- Доступ к панелям по адресу `http://127.0.0.1:PORT`

## Управление процессами

### Жизненный цикл процесса
1. **Запуск**: Создание нового процесса с изолированной средой
2. **Мониторинг**: Отслеживание состояния и здоровья процесса
3. **Перезапуск**: Корректный перезапуск при ошибках
4. **Остановка**: Корректное завершение работы с закрытием позиций

### Обработка сигналов
- `SIGTERM` / `SIGINT`: Корректное завершение работы
- Автоматическая очистка ресурсов
- Закрытие позиций перед выходом

## Мониторинг

### Информация о статусе
Каждый робот предоставляет:
- Статус процесса (запущен/остановлен)
- Идентификатор процесса (PID)
- Информацию о счёте
- URL визуализации
- Метрики производительности

### Логи
- Индивидуальные файлы логов для каждого счёта: `data/logs/robot_ACCOUNT_ID.log`
- Централизованные логи менеджера
- Структурированное логирование с контекстом

## Обработка ошибок

### Восстановление процессов
- Автоматический перезапуск при неожиданном завершении
- Корректная обработка ошибок API
- Очистка ресурсов при сбоях

### Преимущества изоляции
- Сбой одного счёта не влияет на другие
- Независимое восстановление от ошибок
- Изолированное воздействие рисков

## Интеграция с существующей системой

Многопроцессная система использует существующую архитектуру investRobot:

- **TradingSession**: Каждый процесс запускает полную торговую сессию
- **Стратегии**: Та же система стратегий для каждого счёта
- **Управление рисками**: Индивидуальные риск-менеджеры для каждого счёта
- **Визуализация**: Та же визуализация на основе Dash для каждого счёта
- **DI Контейнер**: Полная инверсия зависимостей на процесс
