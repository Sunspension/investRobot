# 📊 Настройка реальных данных для визуализатора

## 🎯 Зачем нужны реальные данные?

Визуализатор показывает **рыночные данные**:
- 📈 Актуальные цены с биржи
- 💰 Реальные объемы торгов  
- ⏰ Обновление в реальном времени
- 🎯 Точные торговые сигналы

## 🚀 Как настроить за 5 минут

### Шаг 1: Получите доступ к API
1. Откройте [Tinkoff Invest](https://www.tinkoff.ru/invest/)
2. Войдите в личный кабинет
3. Перейдите в "Настройки" → "API"
4. Включите доступ и создайте токен

### Шаг 2: Создайте файл настроек
Создайте файл `.env` в папке проекта:

```env
TINKOFF_TOKEN=ваш_токен_здесь
TINKOFF_ACCOUNT=ваш_номер_счета
SANDBOX_TOKEN=ваш_песочница_токен
```

### Шаг 3: Запустите
```bash
source env/bin/activate
python market_visualizer.py
```

Готово! Откройте http://127.0.0.1:8050 в браузере.

## ✅ Что вы увидите

**Если все настроено правильно:**
- 📊 График с реальными свечами
- 💰 Текущая цена обновляется каждые 5 секунд
- 🎯 Торговые сигналы на основе реальных данных
- 📈 Статистика по ордерам и сделкам

**Если что-то не так:**
- ❌ Приложение покажет точную ошибку
- 📝 Подскажет, что нужно исправить

## 🛠️ Частые проблемы

**"Реальные данные недоступны"**
- Проверьте, что файл `.env` создан
- Убедитесь, что токены скопированы правильно

**"Authentication token is missing"**  
- Токен неправильный или истек
- Создайте новый токен в личном кабинете

**"Не удалось получить данные"**
- Проверьте интернет
- Убедитесь, что API включен в настройках
