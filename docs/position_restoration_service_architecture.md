## 🔧 **Архитектура компонентов:**

### **PositionRestorationService:**
```python
class PositionRestorationService:
    """Сервис для восстановления FIFO данных из API истории операций"""
    
    def __init__(self, api_client: TinkoffAPIClient):
        self._api_client = api_client
        self._logger = get_logger(__name__)
    
    async def restore_fifo_from_api(
        self, 
        api_positions: Dict[str, Position],
        existing_fifo: Dict[str, List[FIFOEntry]],
        days_back: int = 30
    ) -> Dict[str, List[FIFOEntry]]:
        """Восстанавливает FIFO данные из API истории операций"""
```

### **PositionManager (обновленный):**
```python
class PositionManager(PositionManageable):
    def __init__(self, db_path: str, api_client: TinkoffAPIClient, risk_manager):
        # ... существующие поля ...
        self._restoration_service = PositionRestorationService(api_client)
    
    async def sync_on_startup(self, max_retries: int = 3):
        # ... получение позиций из API ...
        
        # Если FIFO пустой, пытаемся восстановить из API
        self._fifo_cache = await self._restoration_service.restore_fifo_from_api(
            api_positions,

        )
```
