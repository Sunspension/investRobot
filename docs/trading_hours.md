# 🕐 Торговые часы Московской биржи

## 📅 Расписание торгов

### Будни (понедельник - пятница)
| Сессия | Время (МСК) | Описание |
|--------|-------------|----------|
| Аукцион открытия | 9:50 - 10:00 | Аукцион открытия |
| Основная | 10:00 - 18:50 | Основная торговая сессия |
| Вечерняя | 19:05 - 23:50 | Вечерняя торговая сессия |

### Выходные (суббота и воскресенье)
| Сессия | Время (МСК) | Описание |
|--------|-------------|----------|
| Аукцион открытия | 9:50 - 10:00 | Аукцион открытия (выходные) |
| Утренняя | 10:00 - 14:00 | Утренняя сессия выходных |
| Вечерняя | 19:05 - 23:50 | Вечерняя сессия выходных |

## 🎯 Особенности Тинькофф

> **Важно**: У брокера Тинькофф торговля фьючерсами и некоторыми акциями доступна в выходные дни!

### Доступные инструменты в выходные:
- ✅ Фьючерсы на индексы (включая FUTIMOEXF000)
- ✅ Фьючерсы на валютные пары
- ✅ Некоторые акции
- ❌ Обычные акции (большинство)

## 🔧 Использование в коде

### Проверка торговых часов:
```python
from robotlib.utils.market_hours import get_market_status, MarketHours
from robotlib.utils.market_hours import get_market_status_with_api, is_trading_time_with_api

# Быстрая проверка (статическое расписание)
status = get_market_status()
print(f"Рынок открыт: {status['is_trading']}")

# Проверка с использованием Tinkoff API (рекомендуется)
import asyncio
async def check_market():
    status = await get_market_status_with_api()
    print(f"Рынок открыт (API): {status['is_trading']}")
    
    is_trading = await is_trading_time_with_api()
    print(f"Торговля идет (API): {is_trading}")

asyncio.run(check_market())

# Подробная информация
schedule_info = MarketHours.get_trading_schedule_info()
print(f"Тип дня: {schedule_info['day_type']}")
for session in schedule_info['trading_sessions']:
    print(f"- {session['name']}: {session['start']} - {session['end']}")
```

### Автоматическая проверка в торговой системе:
```python
# Торговая система автоматически проверяет часы
session = TradingSession(config, token, account_id)
await session.start()  # Проверяет торговые часы автоматически (с API если доступно)
```

### Использование Tinkoff API:
```python
from robotlib.utils.tinkoff_market_hours import TinkoffMarketHours

# Создание экземпляра для работы с API
market_hours = TinkoffMarketHours(token="your_token", sandbox=True)

# Получение расписания через API
schedule = await market_hours.get_trading_schedule()
print(f"Расписание на {len(schedule['days'])} дней")

# Проверка торговых часов
is_trading = await market_hours.is_trading_time()
print(f"Торговля идет: {is_trading}")
```

## ⚠️ Важные моменты

1. **Время московское**: Все времена указаны в московском времени (МСК)
2. **Автоматическая проверка**: Торговая система автоматически проверяет часы
3. **Принудительный запуск**: Можно использовать `--force-start` для тестирования
4. **Выходные торговли**: Доступны для фьючерсов и некоторых акций
5. **Перерывы**: Между сессиями есть перерывы (18:50-19:05, 14:00-19:05 в выходные)
6. **Аукцион открытия**: Торги начинаются с аукциона открытия в 9:50

## 🔌 Интеграция с Tinkoff API

### Преимущества использования API:
- ✅ **Актуальные данные** - получаем реальное расписание от биржи
- ✅ **Автоматические изменения** - учитывает праздники и изменения расписания
- ✅ **Детальная информация** - премаркет, клиринг, аукционы
- ✅ **Fallback система** - автоматически переключается на статическое расписание при ошибках

### Ограничения API:
- ⚠️ **Доступность** - API может быть недоступен
- ⚠️ **Лимиты** - ограничения на количество запросов
- ⚠️ **Задержки** - время ответа может быть больше

### Рекомендации:
1. **Используйте API** для продакшена
2. **Настройте fallback** на статическое расписание
3. **Кэшируйте результаты** для снижения нагрузки
4. **Мониторьте ошибки** и логируйте проблемы

### Настройка в торговой системе:
Торговая система автоматически пытается использовать API, но при ошибках переключается на статическое расписание. Это обеспечивает надежность работы.
