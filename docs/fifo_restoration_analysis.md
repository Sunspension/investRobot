## 🔍 **Что возвращает Tinkoff API Operations:**

### **Структура Operation:**
```python
class Operation:
    id: str                    # ID операции (уникальный)
    operation_type: int        # Тип операции (1=покупка, 2=продажа)
    date: datetime             # Время операции (точное время)
    figi: str                  # FIGI инструмента
    quantity: int              # Количество (положительное/отрицательное)
    price_units: int           # Цена в единицах
    price_nano: int            # Цена в наносекундах (точность)
    # ... другие поля
```

### **Что можно восстановить:**

#### **1. Последовательность операций:**

## 🔧 **Реализация восстановления:**

### **1. Запрос истории операций:**
```python
# Запрашиваем историю за последние 30 дней
from_date = datetime.now() - timedelta(days=30)
to_date = datetime.now()

operations = await self._api_client.get_operations_history(from_date, to_date)
```

### **2. Фильтрация по FIGI:**
```python
# Фильтруем операции по FIGI
relevant_operations = [
    op for op in operations 
    if hasattr(op, 'figi') and op.figi == figi
]
```

### **3. Сортировка по времени (FIFO):**
```python
# Сортируем операции по времени (FIFO)
relevant_operations.sort(key=lambda op: op.date)
```

### **4. Создание FIFO записей:**
```python
# Создаем FIFO записи из операций
for op in relevant_operations:
    direction = OrderDirection.BUY if op.quantity > 0 else OrderDirection.SELL
    
    # Извлекаем цену
    price = op.price_units + op.price_nano / 1_000_000_000
    
    fifo_entry = FIFOEntry(
        figi=figi,
        direction=direction,
        quantity=abs(op.quantity),
        price=price,
        timestamp=op.date,
        order_id=op.id
    )
```
