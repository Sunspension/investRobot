### 1. Исправление ошибки NoneType в MarketDataStream.stop()

**Тип ошибки:** `TypeError: object NoneType can't be used in 'await' expression`

**Файлы:** 
- `robotlib/trading/market_data_stream.py`

**Описание проблемы:**
При остановке стрима рыночных данных возникала ошибка из-за попытки выполнить `await` на результате синхронного метода `AsyncMarketDataStreamManager.stop()`, который возвращает `None`.

**Корневая причина:**
- `AsyncMarketDataStreamManager.stop()` из библиотеки Tinkoff - синхронный метод
- Наш `MarketDataStream.stop()` - асинхронный метод (реализует интерфейс `MarketDataStreamable`)
- Смешивание синхронных и асинхронных вызовов

**Решение:**
```python
# ДО (неправильно):
result = self._stream_manager.stop()
if asyncio.iscoroutine(result):
    await result

# ПОСЛЕ (правильно):
self._stream_manager.stop()  # Простой синхронный вызов
```

**Изменения:**
- Убрана проверка `asyncio.iscoroutine(result)`
- Упрощен код до простого синхронного вызова
- Сохранена асинхронность метода для совместимости с интерфейсом

### 2. Улучшение обработки исключений в SessionController

**Файлы:**
- `robotlib/trading/session_controller.py`

**Описание проблемы:**
При `KeyboardInterrupt` или критических ошибках в `run_trading_loop()` не вызывался метод `stop()`, что могло привести к некорректному завершению сессии и утечкам ресурсов.

**Решение:**
```python
except KeyboardInterrupt:
    self.logger.info("Получен сигнал остановки")
    await self.stop()  # ← Добавлено
except Exception as e:
    self.logger.error(f"Критическая ошибка в торговом цикле: {e}")
    await self.stop()  # ← Добавлено
```

**Изменения:**
- Добавлен вызов `await self.stop()` при `KeyboardInterrupt`
- Добавлен вызов `await self.stop()` при критических ошибках
- Обеспечен graceful shutdown во всех сценариях
