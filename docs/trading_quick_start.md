# Быстрый старт торговой системы

## Что реализовано

### Архитектура
- **MarketHours** - проверка торговых часов Московской биржи
- **OrderExecutor** - выполнение торговых приказов через Tinkoff API
- **PortfolioManager** - управление портфелем и позициями
- **RiskManager** - контроль рисков и лимитов
- **TradingSession** - основная торговая сессия

### Безопасность
- Проверка торговых часов
- Контроль размера позиций
- Лимиты дневных убытков
- Стоп-лосс и тейк-профит
- Автоматическое закрытие позиций в конце дня

### Функционал
- Поддержка песочницы и реальной торговли
- Интеграция с существующими стратегиями (Long/Short)
- Детальное логирование
- Статистика торговли
- CLI интерфейс

## Быстрый запуск

### 1. Тестирование в песочнице:
```bash
python main_trading.py --figi FUTIMOEXF000 --deposit 50000 --percent-from-deposit 40
```

### 2. С кастомными параметрами:
```bash
python main_trading.py \
  --figi FUTIMOEXF000 \
  --deposit 100000 \
  --percent-from-deposit 50 \
  --items-per-trade 5 \
  --macd-fast 10 \
  --macd-slow 15 \
  --macd-signal 11 \
  --max-position-size 50000 \
  --max-daily-loss 2500 \
  --stop-loss-percent 3 \
  --take-profit-percent 8
```

### 3. Принудительный запуск (когда рынок закрыт):
```bash
python main_trading.py --force-start --figi FUTIMOEXF000
```

### 4. Реальная торговля (осторожно!):
```bash
python main_trading.py --live-trading --figi FUTIMOEXF000
```

## Основные параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--figi` | FIGI инструмента | FUTIMOEXF000 |
| `--deposit` | Размер депозита в рублях | 100000 |
| `--percent-from-deposit` | Процент от депозита | 50 |
| `--items-per-trade` | Лотов за сделку | 5 |
| `--live-trading` | Реальная торговля | False (песочница) |
| `--force-start` | Принудительный запуск | False |

## Торговые часы

Система автоматически проверяет торговые часы Московской биржи:

### Будни (понедельник - пятница):
- **Аукцион открытия**: 9:50 - 10:00 МСК
- **Основная сессия**: 10:00 - 18:50 МСК
- **Вечерняя сессия**: 19:05 - 23:50 МСК

### Выходные (суббота и воскресенье):
- **Аукцион открытия**: 9:50 - 10:00 МСК
- **Утренняя сессия**: 10:00 - 14:00 МСК
- **Вечерняя сессия**: 19:05 - 23:50 МСК

> **Важно**: Торговля фьючерсами и некоторыми акциями доступна в выходные дни!

## Настройка

Убедитесь, что в `config_data/config.py` правильно настроены:
- `tcs_client.token` - токен доступа к API
- `tcs_client.account_id` - ID торгового счета
- `tcs_client.sandbox_token` - токен песочницы (опционально)

## Важные предупреждения

1. **Всегда тестируйте в песочнице** перед реальной торговлей
2. **Начинайте с малых сумм** для проверки стратегии
3. **Мониторьте работу робота** - не оставляйте без присмотра
4. **Устанавливайте разумные лимиты риска**
5. **Регулярно анализируйте результаты**
