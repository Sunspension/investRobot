# КРИТИЧЕСКИ ВАЖНЫЕ ПРАВИЛА

## 🚨 ПРАВИЛО ИМПОРТОВ
**ВСЕГДА** импорты должны быть в начале файла, а НЕ внутри методов!

### ❌ НЕПРАВИЛЬНО:
```python
def some_method(self):
    from some_module import SomeClass  # ❌ Локальный импорт внутри метода
    return SomeClass()
```

### ✅ ПРАВИЛЬНО:
```python
from some_module import SomeClass  # ✅ Импорт в начале файла

def some_method(self):
    return SomeClass()
```

## 🎯 ПРИНЦИПЫ АРХИТЕКТУРЫ
1. **Инверсия зависимостей** - классы зависят от интерфейсов, а не от реализаций
2. **Инъекция зависимостей** - зависимости передаются в конструктор, а не создаются внутри
3. **Разделение ответственности** - каждый класс имеет одну ответственность
4. **Тестируемость** - код должен легко тестироваться с моками
