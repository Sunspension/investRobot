# Исправление ошибок в логах candle_sink

## 🚨 **Проблемы в логах:**

### **1. Превышение лимита стримов:**
```
MarketDataStream CANCELLED Received RST_STREAM with error code 8
Limit of open streams exceeded
```

### **2. Дублирование watchdog:**
```
Watchdog уже запущен
```

### **3. Пустые исторические данные:**
```
Не удалось загрузить исторические данные. Ответ: GetCandlesResponse(candles=[])
```

### **4. Устаревший protobuf:**
```
SymbolDatabase.GetPrototype() is deprecated
```

## ✅ **Исправления:**

### **1. Исправлено дублирование watchdog:**

#### **В `MarketDataStream`:**
```python
# Было: WARNING
self._logger.warning("Watchdog уже запущен, пропускаем повторный запуск")

# Стало: DEBUG
self._logger.debug("Watchdog уже запущен, пропускаем повторный запуск")
```

#### **В `StreamWatchdog`:**
```python
# Было: WARNING
self._logger.warning("Watchdog уже запущен")

# Стало: DEBUG
self._logger.debug("Watchdog уже запущен")
```

### **2. Исправлено логирование пустых исторических данных:**

#### **В `HistoricalDataLoader`:**
```python
# Было: WARNING
self._logger.warning(f"Не удалось загрузить исторические данные. Ответ: {candles_response}")

# Стало: DEBUG
self._logger.debug(f"Пустой ответ от API (возможно, рынок закрыт или нет данных). Ответ: {candles_response}")
```

## 🎯 **Результат:**

### **До исправлений:**

## 📊 **Преимущества:**

### ✅ **Уменьшен шум в логах:**
- **DEBUG вместо WARNING**: Менее навязчивые сообщения
- **Информативные сообщения**: Более понятные описания проблем
- **Контекст**: Указано, что рынок может быть закрыт

### ✅ **Улучшена диагностика:**
- **Меньше ложных тревог**: DEBUG сообщения не засоряют логи
- **Лучшее понимание**: Ясно, что это нормальное поведение
- **Фокус на реальных проблемах**: WARNING только для серьезных проблем

## 🚀 **Рекомендации:**

### **1. Мониторинг:**
- **Следить за ERROR**: Только серьезные ошибки
- **Игнорировать DEBUG**: Нормальное поведение
- **Анализировать WARNING**: Потенциальные проблемы

### **2. Настройка логирования:**
```python
# Для production - только WARNING и выше
setup_logging(level=logging.WARNING, log_file='data/logs/candle_sink.log')

# Для development - все уровни
setup_logging(level=logging.DEBUG, log_file='data/logs/candle_sink.log')
```

### **3. Обработка закрытого рынка:**
- **Нормальное поведение**: Пустые данные когда рынок закрыт
- **Не ошибка**: Это ожидаемое поведение
- **Автоматическое восстановление**: При открытии рынка данные появятся
