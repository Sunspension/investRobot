## 🎯 БЫСТРЫЕ ПРОВЕРКИ:

### Поиск нарушений:
```bash
# Поиск hasattr для собственных атрибутов
grep -r "hasattr.*self\." --include="*.py" .

# Поиск прямого доступа к приватным атрибутам
grep -r "self\.[a-z][a-zA-Z0-9_]*\." --include="*.py" .

# Поиск создания зависимостей внутри класса
grep -r "= [A-Z][a-zA-Z]*(" --include="*.py" .
```

### Запуск проверок:
```bash
# Тесты
python -m pytest tests/ -v

# Линтер
python -m flake8 .

# Проверка типов
mypy .
```
