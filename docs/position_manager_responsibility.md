#### **1. PositionManager теперь отвечает за:**
- ✅ **Расчет убыточных позиций** по FIFO
- ✅ **Расчет прибыльных позиций** по FIFO  
- ✅ **Управление FIFO очередью** для каждого FIGI
- ✅ **Синхронизацию с API** для восстановления данных

- ✅ **Запрашивают данные** у PositionManager
- ✅ **Принимают решения** на основе полученных данных
- ✅ **Создают ордера** для закрытия позиций

```python
async def _check_stop_loss(self, candle: Candle | HistoricCandle) -> list[OrderIntent]:
    """Проверяет стоп-лосс для лонг позиций"""
    current_price = Money(candle.close).to_float()
    
    # Получаем убыточные позиции от PositionManager
    loss_positions = await self._position_manager.get_loss_positions(
        self._figi, 
        current_price
    )
    
    if loss_positions:
        total_qty = sum(pos.quantity for pos in loss_positions)
        orders.append(OrderIntent(
            direction=OrderDirection.SELL,  # продаем лонг при стоп-лоссе
            quantity=total_qty,
            order_type=OrderType.MARKET,
            figi=self._figi,
            strategy="stop_loss"
        ))
    
    return orders
```

## 📊 **Преимущества новой архитектуры:**

### **1. Централизация логики:**
- ✅ **Один источник истины** для FIFO расчетов
- ✅ **Единая логика** для всех стратегий
- ✅ **Консистентность** данных между стратегиями

### **2. Упрощение стратегий:**
- ✅ **Стратегии не содержат** сложную FIFO логику
- ✅ **Фокус на торговой логике**, а не на расчетах
- ✅ **Легче тестировать** и поддерживать

### **3. Восстановление данных:**
- ✅ **Автоматическое восстановление** FIFO из API
- ✅ **Синхронизация** с брокером при старте
- ✅ **Отказоустойчивость** при потере локальных данных

### **4. Гибкость:**
- ✅ **Настраиваемые пороги** убытков
- ✅ **Поддержка разных стратегий** (лонг/шорт)
- ✅ **Расширяемость** для новых типов позиций
