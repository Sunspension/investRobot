### **2. Проверка структуры данных**

#### **Валидация каждой позиции:**
```python
# Проверяем типы данных
assert isinstance(position.figi, str)           # FIGI должен быть строкой
assert isinstance(position.quantity, (int, float))  # Количество должно быть числом
assert position.quantity != 0                   # Количество не должно быть нулевым
assert isinstance(position.avg_price, (int, float))  # Средняя цена должна быть числом
assert isinstance(position.last_updated, datetime)   # Время обновления должно быть datetime
```

#### **Проверка содержимого:**
```python
# Проверяем логические ограничения
assert len(position.figi) > 0                  # FIGI не должен быть пустым
assert position.quantity > 0                    # Количество должно быть положительным
assert position.avg_price >= 0                 # Средняя цена не должна быть отрицательной
```

### **3. Обработка ошибок**

#### **Типичные ошибки и их причины:**

##### **❌ "Позиция X: отсутствует FIGI"**
- **Причина**: API вернул позицию без FIGI
- **Решение**: Позиция пропускается, система продолжает работу

##### **❌ "Позиция X: отсутствует количество"**
- **Причина**: API вернул позицию без количества
- **Решение**: Позиция пропускается, система продолжает работу

##### **❌ "Позиция X: неверный тип количества"**
- **Причина**: API вернул количество в неожиданном формате
- **Решение**: Позиция пропускается, система продолжает работу

##### **❌ "Позиция X невалидна: FIGI должен быть строкой"**
- **Причина**: Ошибка в создании объекта Position
- **Решение**: Позиция удаляется из результата

### **4. Мониторинг качества данных**

#### **Метрики для отслеживания:**
```python
# Количество позиций в API ответе
api_positions_count = len(portfolio_response.positions)

# Количество успешно конвертированных позиций
converted_positions_count = len(positions)

# Количество валидных позиций
valid_positions_count = sum(1 for p in positions.values() if p.quantity > 0)

# Процент успешной конвертации
conversion_rate = (converted_positions_count / api_positions_count) * 100 if api_positions_count > 0 else 0
```

#### **Ожидаемые значения:**
- **conversion_rate >= 95%** - хорошее качество конвертации
- **conversion_rate >= 80%** - приемлемое качество конвертации
- **conversion_rate < 80%** - требуется исследование проблем

### **5. Автоматические проверки**

#### **Проверка консистентности с PortfolioManager:**
```python
# Сравниваем количество позиций
portfolio_positions = len(portfolio_manager.get_portfolio().positions)
position_manager_positions = len(position_manager._positions_cache)

if portfolio_positions != position_manager_positions:
    logger.warning(f"Расхождение: PortfolioManager={portfolio_positions}, PositionManager={position_manager_positions}")
```

#### **Проверка актуальности данных:**
```python
# Проверяем, что данные не старше 5 минут
max_age = datetime.now() - timedelta(minutes=5)
for position in positions.values():
    if position.last_updated < max_age:
        logger.warning(f"Позиция {position.figi} устарела: {position.last_updated}")
```
