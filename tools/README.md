# Tools

Папка содержит инструменты (shell-скрипты) для запуска основных компонентов проекта.

## Доступные скрипты

### 🚀 run_optimization.sh
Запускает оптимизацию торговых стратегий для всех доступных дней.

**Использование:**
```bash
./tools/run_optimization.sh
```

**Что делает:**
- Активирует виртуальное окружение
- Создает папки для логов и результатов
- Запускает оптимизацию в фоновом режиме
- Показывает PID процесса и путь к лог-файлу

### 📊 run_visualizer.sh
Запускает визуализатор рыночных данных.

**Использование:**
```bash
./tools/run_visualizer.sh
```

**Что делает:**
- Активирует виртуальное окружение
- Запускает `tools/market_visualizer.py`
- Открывает браузер на `http://localhost:8050`

### 📅 run_all_days_optimization.sh
Запускает оптимизацию для всех дней с мониторингом.

**Использование:**
```bash
./tools/run_all_days_optimization.sh
```

### 👁️ monitor_all_days.sh
Мониторит процесс оптимизации всех дней.

**Использование:**
```bash
./tools/monitor_all_days.sh
```

### 🧪 run_tests.py
Запускает все тесты проекта.

**Использование:**
```bash
python tools/run_tests.py
```

### 🔬 run_core_tests.py
Запускает основные тесты проекта.

**Использование:**
```bash
python tools/run_core_tests.py
```

### 📊 market_visualizer.py
Точка входа для визуализатора рыночных данных.

**Использование:**
```bash
python tools/market_visualizer.py
```

## Быстрый старт

1. **Запуск визуализатора:**
   ```bash
   ./tools/run_visualizer.sh
   ```

2. **Запуск оптимизации:**
   ```bash
   ./tools/run_optimization.sh
   ```

3. **Мониторинг оптимизации:**
   ```bash
   tail -f data/logs/optimization_*.log
   ```

## Примечания

- Все скрипты автоматически активируют виртуальное окружение
- Логи сохраняются в `data/logs/`
- Результаты оптимизации сохраняются в `data/optimization_results/`
- Для остановки процессов используйте `Ctrl+C` или найдите PID и выполните `kill <PID>`
