# Оптимизация торговых стратегий

## 🚀 Универсальный оптимизатор

### `optimizer.py` - Универсальная оптимизация
**Единственный файл для всех задач!**
- **Скорость:** ~100,000 комб/сек
- **Гибкость:** Поддержка одного дня, массива дат или периода
- **Точность:** Максимальная с Numba оптимизацией
- **Метод:** Быстрые вычисления с JIT компиляцией
- **Параметры:** Гибкая настройка через командную строку
- **Результаты:** Автоматическое сохранение в JSON

## 📊 Результаты тестирования

### Лучшие результаты (2024-12-02):
- **Доход:** 60,700 руб
- **Параметры:** MACD(6,16,7) ATR(10) Lookback(4-19) Prominence(0.15)

### Диапазоны параметров оптимизации:
- **macd_fast:** 5-20
- **macd_slow:** 10-30
- **macd_signal:** 5-15
- **atr_period:** 8-15
- **lookback_min:** 3-20
- **lookback_max:** 10-30
- **peak_prominence:** 0.1, 0.15, 0.2, 0.25, 0.3

## 🚀 Запуск

### Оптимизация конкретных дней:
```bash
python optimization/optimizer.py --days 2024-12-02 2024-12-03 2024-12-04
```

### Оптимизация периода:
```bash
python optimization/optimizer.py --start 2024-12-01 --end 2024-12-10
```

### Оптимизация всех дней:
```bash
python optimization/optimizer.py --all
```

### Быстрый запуск (последние 5 дней):
```bash
python optimization/optimizer.py
```

### Дополнительные параметры:
```bash
# Ограничить количество комбинаций
python optimization/optimizer.py --days 2024-12-02 --max-combinations 50000

# Показать справку
python optimization/optimizer.py --help
```
